# Portfolio de Maquetación de Emails - Frontend / Email Developer

Colección de plantillas de correo electrónico, maquetación (compatible con clientes modernos y Outlook) y optimizadas para campañas de marketing.

## 🚀 Enlace en Vivo (GitHub Pages)
Puedes visualizar las plantillas renderizadas en tiempo real haciendo clic aquí:
👉 [https://mlbri.github.io/maquetacion-email-templates/](https://mlbri.github.io/maquetacion-email-templates/)

## 📂 Contenido del Portfolio
* **Práctica 1 (noticias1):** Newsletter de noticias con estructura híbrida, diseño adaptativo y soporte automático para Light / Dark Mode.
* **Práctica 2 (noticias2):** Newsletter con diseño de fondo permanente.

## 🛠️ Tecnologías y Prácticas Utilizadas
* HTML5 semántico para emails y CSS inlined.
* Media Queries *.
* Comentarios condicionales MSO para renderizado perfecto en Microsoft Outlook.
* Uso eficiente de variables y utilidades de espaciado con márgenes controlados.
